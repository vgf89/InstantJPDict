LLVM OpenMP runtime (libomp)
============================

Bundled as   : lib/arm64-v8a/libomp.so (1.2 MB), packaged by the Android Gradle
               Plugin because the app's CMake build links OpenMP
               (app/src/main/cpp/CMakeLists.txt: find_package(OpenMP) →
               OpenMP::OpenMP_CXX). ncnn's own parallel-for runs on this runtime.
Origin       : the Android NDK's clang runtime —
               $ANDROID_NDK/toolchains/llvm/prebuilt/linux-x86_64/lib/clang/19/lib/linux/aarch64/libomp.so
               with NDK 28.2.13676358, the version pinned in app/build.gradle.kts.
Upstream     : https://github.com/llvm/llvm-project (compiler-rt / openmp runtimes)
